The Funnel

三关漏斗 · 四道门

每一关都是「硬过滤」，不通过的直接淘汰，不做「综合评分」和稀泥。

第零关
宏观
  • 涨跌家数：上涨 < 3000 只 → 不买
  • 美股三大 / 日经 / KOSPI 昨夜走势
  • 北向资金近期流向
第一关
板块
  • 板块涨幅排行 TOP 共振
  • 排除宏观回避方向
  • 北向增持板块交叉验证
第二关
个股
  • 当日涨幅 3%–7%（不追涨停）
  • 量比 ≥ 1.5，MA20 向上
  • 排除 ST / 300 / 688
  • 消息面排雷（减持/亏损/质押/立案）
第三关
买点
  • 窗口：10:40 前 或 14:40 后
  • 分时回踩分时均线
  • 给出买入 / 止损 / 止盈价
Self-Improving

递归自我改进引擎

套在漏斗外层，把「门槛规则」当成可优化的对象，靠回测验证、只采纳真能提升 EV 的改动。

L1 · 策略代际

V6 → V7 → V8

每代只采纳 1 项最小改动，可回滚、可对比。代际之间口径统一。

L2 · 门规搜索

家族通过率 → 预算分配

候选改动按「家族通过率」加权，决定下一代把变异预算投给哪类改动。

L3 · 元记录

账本 + 全量日志

所有候选 + 采纳/拒绝理由全部落账，可追溯、可复现。

随机变异→ 门规验证→ 采纳 / 拒→ 迭代→ 无改善即停
门规验证用 AEV / bootstrap / 副径 三门槛（精确定义待补全）。纪律：收盘后启动（无未来函数），逻辑改动必须回测验证。
